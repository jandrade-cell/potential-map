Data files

Everything stays in this browser. Files are read on your computer; only Modoc County rows (plus statewide rows, for comparison) are kept. Nothing is uploaded anywhere.

Drop files here or click to choose
.zip, .txt, or .csv · Dashboard download files, CAASPP and ELPAC research files

1 · CA School Dashboard files

  1. Go to CDE's Accountability Downloadable Files page.
  2. Open each indicator you want (ELA, Mathematics, Science, Chronic Absenteeism, Suspension, Graduation, English Learner Progress, College/Career) and download the year's .txt file, e.g. eladownload2026.txt.
  3. Drop them here. These are statewide files (15–30 MB each); the hub keeps only Modoc and state rows.

2 · CAASPP and ELPAC research files

Same steps on each page: Smarter Balanced (ELA/Math) · CAST (Science) · Summative ELPAC

  1. Choose the year and set County to Modoc. Download the caret-delimited (“csv”) All Student Groups file for Modoc. It is small, and it includes school and district names.
  2. For a statewide comparison, switch County back to Statewide and download the All Students file (2–8 MB).
  3. Drop the .zip files here as they are. You don't need the separate Entities or Student Groups files.

Load several years of any source to see trends. Loading a file again replaces its rows instead of adding duplicates.
