How it stays current
  1. Every result is stored as a dated point on a timeline (baseline, Year 1, Year 2, then anything you add).
  2. Each metric's status (Priority, Watch, Sustain) is recalculated from the latest point, the baseline, and the target every time data changes.
  3. Insights and the next-cycle summary are regenerated from the rules instantly; with an API key you can also have Claude rewrite them in narrative form.
  4. Data stays in this browser. Use Save File to share with your team or move to another computer.
